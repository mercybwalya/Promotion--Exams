# Student Record Management System
A console-based system for managing student academic records in C.

## Features
- Add, view, search students
- Calculate results (total, average, grade)
- Save records to `students.txt`

## How it works
1. Menu-driven interface
2. Uses structures for data storage
3. File handling for saving records

## Requirements
- C compiler (e.g., GCC)

## Usage
1. Compile: `gcc student_system.c -o student_system`
2. Run: `./student_system`

## Files
- `student_system.c`: Source code
- `students.txt`: Saved records
